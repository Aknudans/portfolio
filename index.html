03

Proyectos

P.1

Talana Docs Downloader

Aplicación web en Flask que se conecta a la API de RRHH de Talana para buscar personas por RUT o nombre y descargar en lote sus documentos firmados, en vez de hacerlo uno por uno a mano. Soporta búsqueda masiva pegando listas desde Excel, filtra automáticamente qué documentos corresponden, arma un ZIP organizado por persona y entrega un resumen descargable de los casos que fallaron. Se puede instalar como app de escritorio desde el navegador.

Desarrollado para Grupo Colchagua ↗

GitHub ↗
P.2

OptiPDF Merger

Utilidad que fusiona múltiples PDFs en un único documento y lo comprime de forma agresiva sin perder legibilidad, pensada para cumplir límites estrictos de tamaño de archivo. Corre un pipeline de tres etapas — fusión con pypdf, optimización estructural con qpdf y compresión por fases con Ghostscript — y puede usarse desde línea de comandos o desde una interfaz web local.

Desarrollado para Grupo Colchagua ↗
PythonqpdfGhostscript
GitHub ↗
P.3

Bot ShiftLaboral

Bot de automatización (RPA) que carga colaboradores y sus documentos en ShiftLaboral, un sistema externo sin API pública ni carga masiva. A partir de un Excel, compara los datos contra lo ya registrado, crea o edita colaboradores corrigiendo solo los campos que difieren, y sube sus documentos detectando el tipo de archivo automáticamente. Al finalizar genera un reporte Excel coloreado con el detalle de cada caso. Corre sobre una sesión de Chrome iniciada manualmente, sin manejar contraseñas.

Desarrollado para Grupo Colchagua ↗
PythonPlaywrightRPA
GitHub ↗
P.4

Cpiel Reloj Control

Sistema de notificaciones para un reloj control de asistencia: revisa marcajes recientes, descubre el esquema de la base de datos automáticamente y avisa por correo y por popup en escritorio cuando corresponde, para no tener que revisar la asistencia a mano.
