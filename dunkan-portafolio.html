03

Proyectos

P.1

Talana Docs Downloader

Aplicación web en Flask que se conecta a la API de RRHH de Talana para buscar personas por RUT o nombre y descargar en lote sus documentos firmados, en vez de hacerlo uno por uno a mano. Soporta búsqueda masiva pegando listas desde Excel, filtra automáticamente qué documentos corresponden, arma un ZIP organizado por persona y entrega un resumen descargable de los casos que fallaron. Se puede instalar como app de escritorio desde el navegador.

PythonFlaskAPI REST
GitHub ↗
P.2

OptiPDF Merger

Utilidad que fusiona múltiples PDFs en un único documento y lo comprime de forma agresiva sin perder legibilidad, pensada para cumplir límites estrictos de tamaño de archivo. Corre un pipeline de tres etapas — fusión con pypdf, optimización estructural con qpdf y compresión por fases con Ghostscript — y puede usarse desde línea de comandos o desde una interfaz web local.

PythonqpdfGhostscript
