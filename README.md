# Portafolio — Dunkan Hernández Reyes

Landing page de una sola página que funciona como currículum interactivo, pensada para usar en entrevistas y postulaciones.

🔗 **Sitio publicado:** https://aknudans.github.io/portfolio/

## Sobre el proyecto

Sitio estático hecho en HTML y CSS puro, sin frameworks ni dependencias de build. Un solo archivo (`index.html`) contiene todo el markup y los estilos.

Secciones: Sobre mí, Stack, Proyectos, Experiencia, Educación y Contacto.

## Estructura

```
index.html          # Página principal (todo el sitio)
docs/
  Curriculum.pdf     # CV descargable, enlazado desde el sitio
```

## Desarrollo local

No requiere instalación ni servidor: basta con abrir `index.html` directamente en el navegador.

## Deploy

El sitio se publica con **GitHub Pages** (deploy clásico desde la rama `master`, carpeta raíz). Cada push a `master` actualiza el sitio automáticamente.
